# REVIEW.md — контракт ревью этого проекта

> Читает ревьюер (reviewer-hub DeepSeek / GLM-5.3-Flash / Astra / Claude code-reviewer) вместе с дифом.
> Решение владельца 2026-10-31 (П1). Проект: claude-codex-limits — macOS-приложение в строке меню (Swift, AppKit, macOS 13+) + Linux-издатель (Python), обмен через приватный gist.

## Что здесь считается багом (отказ)
- Утечка секрета: токен GitHub/Claude/Codex, почта, путь `/Users/…`, hostname, `accountUuid` — в gist, журнал, `poll-log`, argv, окружение, AX, текст ошибки.
- Запись в файлы входа CLI (`credentialWrite` по умолчанию `never`), разлогин или удаление пункта Связки без подтверждённой причины; системное окно пароля в фоне.
- Нарушение протокола `docs/sync-protocol.md` (v1.1): порядок тика, отпечатки записи, merge подписей по `setAt`, обратная совместимость с читателями 3.2.7 / Linux 0.4.5.
- Опрос провайдера чаще расписания или мимо `serverRetryAt`/429; Auto, залипший на 15 мин.
- Расхождение отрисовки с моделью высот (наложения, неравные карточки), обрезанные дата/время/`›`, тексты RU/EN не по `design/remote-limits-ux.md`.
- Тест, который зелёный при сломанном поведении (проверяет модель, а не то, что рисуется/отправляется).

## Что НЕ смотреть
- `docs/**`, `HEARTBEAT.md`, `decisions/**`, `backlog.md`, `.patches/**` — журналы процесса.
- `fixtures/**` (кроме смысла новой фикстуры), PNG-превью, `dist/`, `.build-tmp/`, `.signing/`.
- Deprecation-предупреждения `SecKeychain*` (осознанный выбор для macOS 13).

## Формат ответа ревьюера (обязателен)
1. Первая строка: `Important: N · Nit: M · Pre-existing: K`.
2. Каждая находка — тег `Important` / `Nit` / `Pre-existing`, затем `путь:строка`, **сценарий отказа** (вход → неверный результат), предложение. Без `путь:строка` и сценария находка не считается.
3. `Important` — поведение/данные/безопасность/контракт; `Nit` — стиль, имена, мелкая читаемость; `Pre-existing` — было до этого дифа.
4. Стиль/cleanup без влияния на поведение не перечислять.
5. Повторный круг: только новый диф; находки из списка «закрыто» не повторять; одинаковые баги — одним пунктом «класс бага».

## Что делает автор (Sol) с находками
- Чинит **только Important** (после «докажи или сними» на GLM-5.3-Flash, если Important ≥ 3 или ревью перед установкой). `Nit` → «Долг» в HEARTBEAT.md. `Pre-existing` → отдельный урок/задача.
