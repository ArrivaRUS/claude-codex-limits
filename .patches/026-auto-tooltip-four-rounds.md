# 026 — Подсказка «А»: простая правка текста ушла в 4 сборки у владельца

**Дата:** 2026-11-04 · **Версии:** 95cefbb → 28f3c5f → 7a8e3ff → (fix7)

## Что случилось
Владелец попросил, чтобы подсказка кнопки «А» говорила и про продукт с другой машины. Ушло четыре круга «Sol → коммит (хук ~10 мин) → сборка владельца»:
1. Sol отправлен править `RemoteAutoFooter.tooltip`, а подсказку «А» на панели собирает `remotePollTooltip(0, …)` (`RemoteLimitsC3B.swift`). Юрка не проверил, откуда берётся видимый текст («30 минут» ≠ «30 мин» в той функции) — нашёл только после запуска.
2. Владелец выбрал показанный Юркой текст, а Юрка уже отдал Sol «готовую подсказку легенды» — другую формулировку (нарушение урока памяти «выбор владельца = ровно тот вариант»).
3. Сам предложенный текст был плохим: вторая строка «Claude Code опрашивает vps, каждые 15 мин — менять на vps» в другой стилистике, чем первая «Авто: Codex → 30 минут», плюс канцелярское «менять на vps». Владелец увидел живьём → «бредовая надпись».
4. После правки слов стиль всё равно разный («→ 15 минут» против «опрашивает vps, каждые 15 мин»).

Попутно: три сборки (95cefbb, 28f3c5f, 7a8e3ff) отданы владельцу без прогона удалённых рук — повтор уроков 023/025 (владелец снова в роли компилятора; на этот раз компиляция проходила, но правило нарушено).

## Правило на будущее
- **Перед брифом на видимый текст — найти функцию, которая его рисует, по точной строке со скрина** (`grep` фразы с экрана), а не по смыслу.
- **Предлагая текст владельцу из нескольких строк — один шаблон для всех строк** («<продукт> → <значение> (<машина>)»): одинаковые единицы («15 минут», не «15 мин» рядом с «30 минут»), без служебных хвостов («менять на …»). Прочитать предложенное вслух как пользователь до отправки.
- **Утверждённый владельцем текст уходит в бриф дословно**, в блоке кода, RU и EN; «переиспользуй готовую строку» — только если она совпадает с утверждённой байт-в-байт.
- Правило 023/025 уточнено: пока `git-pull ccl` у удалённых рук отклонён диспетчером, `git fetch` всё равно делает владелец — тогда «fetch + сборка + тесты» одной командой стоит ему одно действие, а «fetch → удалённые руки → сборка» — два. Удалённые руки первыми — когда правка рискованна для компиляции (новые типы/сигнатуры в нескольких файлах) или после FAIL; для правок литералов — сразу общая команда. Починить `git-pull ccl` — долг тулинга, после него правило 023 снова безусловное.
