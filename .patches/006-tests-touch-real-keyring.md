# 006 — Автотест интерфейса удалил настоящий токен GitHub и записал лишний файл в gist

**Дата:** 2026-09-27 · **Где:** Linux-порт, ручной смоук-тест во время разработки

## Что случилось

Смоук-тест значка запускался с временными `XDG_CONFIG_HOME`/`XDG_STATE_HOME` в расчёте на
изоляцию. Но хранилище секретов (KWallet через `org.freedesktop.secrets`) от XDG-переменных
не зависит. Тест:
1. прочитал настоящий токен GitHub и с **новым** временным machine-id записал в gist второй
   файл `astra-23876` — Mac посчитал бы расход Astra дважды;
2. нажал «Выйти» и удалил настоящий токен из KWallet — владельцу пришлось входить заново.

Лишний файл удалён из gist вручную (он остаётся в истории ревизий gist).

## Правило

Любой тест или скрипт, который создаёт `TrayApp` или вызывает `sync`/`vault`, обязан заглушить
`vault._ss` (или `vault.read`) и `sync.sync_cycle`. Изоляция через XDG-папки не распространяется
на keyring, gist и файлы учётных данных CLI. Образец — `linux/tests/gui_width_probe.py`.
