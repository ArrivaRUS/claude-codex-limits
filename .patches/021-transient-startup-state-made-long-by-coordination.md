# 021 — Codex двумя карточками: временное состояние после старта стало многочасовым из-за координации C4

**Дата:** 2026-11-01 · **Веха:** C5 (регресс C4) · **Тест:** C5-19

## Что случилось

Владелец увидел в Simple две карточки Codex (`macbook` 49 %, рыжая точка, и `vps` 57 %, зелёная) и шапку `… · Codex · Codex`. У обеих машин одна label аккаунта. 29.10 на `078de62` та же пара была одной карточкой.

Причина состояла из двух частей.

- **Скрытый с C2 разрыв.** Писатель кэша сохраняет `accountId` рядом с процентами (`RemoteLimitsC4.swift:588`), а загрузка при старте читала кэш через `dict2ld` и id отбрасывала. До первого свежего опроса своя карточка жила без label, и резолвер не склеивал её с чужой карточкой того же аккаунта.
- **C4 растянул разрыв на часы.** Координация B2 (`remote_attempt`/`fresh_remote`, `ad3eb86`) по замыслу откладывает свой опрос, пока VPS публикует свежие данные. Поэтому первый свой опрос, который вернул бы id, после перезапуска не наступал часами. Раньше разрыв длился секунды и не был виден.

Тесты C4 проверяли резолвер на показаниях с уже заполненной label, то есть в состоянии после свежего опроса. Состояние «загружено из кэша, своего опроса ещё не было» не проверял ни один тест. До фикса `a45227e` дефект дошёл до установки у владельца.

## Правило на будущее

1. **Если изменение продлевает жизнь переходного состояния (загружено из кэша, опрос отложен, ожидание сети), это состояние становится штатным.** В том же заходе нужен тест модели, нарисованной именно из него, а не из состояния после свежего опроса.
2. **Сохранённое поле обязано читаться обратно.** Если писатель кладёт поле в кэш или файл, тест идёт по кругу «писатель → файл → загрузка при старте → модель». Ручная фикстура рядом с писателем такой разрыв не ловит (долг C5-19: фикстура пока ручная).
3. **В брифе фичи, которая подавляет или откладывает действие (координация, бэкофф, пауза), перечислять, что это действие давало попутно** (здесь: свежий опрос попутно восстанавливал идентичность). Каждый такой побочный эффект должен иметь другой источник.
