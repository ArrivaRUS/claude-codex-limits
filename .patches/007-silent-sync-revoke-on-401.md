# 007 — Синхронизация молча выключилась на одном 401

**Дата:** 2026-09-28…30 · **Где:** обе платформы (macOS 3.1.2, Linux 0.3.1)

## Что случилось

С 28.09 обе машины перестали писать в синк-гист. Сводка показывала «Codex сегодня $1», а
реально было ~$42 — почти всё тратил ThinkPad. Один ответ 401 от GitHub → `revoked()`
удалял токен и выключал синхронизацию; предупреждение было только в Настройках, на
главном экране — ничего. Вероятная причина 401: лимит GitHub в 10 токенов на
пользователя/приложение/scope — выход/перевход на другой машине сжёг старейший токен.
На Маке вдобавок гист читался только при изменении локального индекса.

## Почему не поймали

Не было инварианта «синхронизация не может остановиться молча»: ошибки синка жили в
Настройках, а главный экран не знал о простое. Отзыв по одному ответу сети — необратимое
действие на слабом сигнале.

## Правило на будущее

1. Любой фоновый обмен, от которого зависят цифры на главном экране, обязан показывать
   простой там же (строка «стоит с HH:mm: причина» после неудачной попытки и порога).
2. Необратимое действие (удалить токен, выключить функцию) — только на подтверждённом
   сигнале: повторная проверка другим запросом, пауза, ещё раз (вариант «а»).
3. Кросс-платформенный контракт (`docs/sync-protocol.md`) — единственный источник правды;
   ревью сверяет обе платформы с ним, расхождения — находка.
