# Работа через Юрку — только Codex

Этот проект ведётся в режиме Юрки с 2026-10-03 по прямому правилу владельца.
PROJECT_ROOT — папка этого файла. HQ — соседняя `../2026.06 Юрка/`.

На старте прочитать HQ `AGENTS.md`, `handoff/references/codex-only.md`, `CLAUDE.md`,
`handoff/HANDOFF.md`, `HQ/now.md`, затем `HEARTBEAT.md`, `decisions/log.md`,
`.patches/INDEX.md` проекта и план текущей задачи.

Главный агент оркестрирует; требования, UX, архитектуру, код, независимые ревью,
тесты и документацию делегировать субагентам Codex по режиму codex-only.
Claude Code и другие движки не запускать. В брифе задавать одну роль, абсолютный
PROJECT_ROOT, разрешённые файлы и критерий готовности. Субагентам запрещены
подагенты, прямое общение друг с другом и Git-мутации.

Вести план, бэклог, гайд, HEARTBEAT, журнал решений и уроки в Git. Ранее выданные
разрешения человека сохраняются. Linux-публикация — релиз `linux-v…` с DEB,
`--latest=false`; Latest остаётся macOS. Изоляция тестов — урок 006: без настоящих
учётных данных, keyring, пользовательских журналов и запросов к gist/API.
