# Claude Codex Limits — паспорт проекта

Обновлено: 2026-10-03. Корень: `/Users/arrivarus/Documents/VibeCoding2/2026_06_UsageLimits`.

Локальная утилита macOS и Linux показывает лимиты Claude Code и Codex, историю расхода и состояние синхронизации. Основной пользователь выбирает отслеживаемые подписки и частоту опроса. Языки интерфейса — русский и английский.

Проект ведётся через Юрку в [режиме только Codex](../2026.06%20Юрка/handoff/references/codex-only.md): главная сессия координирует отдельные роли Codex; артефакты проекта находятся здесь. Канон текущих требований — [PRD.md](PRD.md), порядок работы — [docs/plans.md](docs/plans.md), живой статус — [docs/status.md](docs/status.md), память — [HEARTBEAT.md](HEARTBEAT.md) и [decisions/log.md](decisions/log.md). Пользовательские инструкции — [README.ru.md](README.ru.md), [README.md](README.md), [linux/README.md](linux/README.md).

## Факт на момент подключения Юрки

По переданному оркестратором состоянию `main` на `e6e2f2e` уже опубликованы macOS 3.2.0 и Linux 0.4.0. До передачи проекта прошли 205 Linux-тестов и Swift selftest. Адаптивный опрос уже реализован одним агентом; независимого ревью этого изменения не было. Эта запись — ретроспектива, а не свидетельство предварительного планирования или пройденных командных гейтов.

Текущая отдельная задача — сделать стилизованную кнопку «А» (Auto) и видимую рядом текущую частоту опроса. Слоты фиксированных 15/30/60 минут не должны получать рамку при включённом Auto. Поведение опроса 15/30/60/240 минут и независимые расписания продуктов уже существуют; задача касается их ясного отображения.
