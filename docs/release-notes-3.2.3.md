# macOS 3.2.3 — черновик выпуска

Статус на 2026-10-04: **validation/build/release pending**. Это описание текущего
изменения, не объявление опубликованного релиза. Координатор добавит фактическую
принятую ревизию, результаты проверок и SHA-256 assets после их выполнения.

## Изменение для пользователя

- Действующий долгоживущий GitHub-вход сохраняет работу без обязательного перевхода.
- Только новый явный вход запрашивает `gist offline_access`; полученные refresh и
  сроки сохраняются, короткий access продлевается автоматически.
- Обслуживание входа и синхронизация независимы от Advanced и Auto лимитов;
  после сна/restart срок оценивается заново. Временные сеть/storage/429/5xx
  сохраняют последнюю надёжную выдачу и используют backoff.
- Состояния хранилища, восстановления и ручного входа различаются. Один timeout
  не означает отзыв GitHub; подтверждение 401 сохраняется с попыткой refresh.
- Выход только локальный. Незавершённое удаление credentials показывается как
  cleanup pending; запоздалый ответ не должен воскресить отключённый вход.
- Старый remote cache без подтверждённой принадлежности аккаунту после restart
  ждёт первого verified sync. Локальная история сохранена.

## Границы и проверки

Внешний отзыв, истёкший refresh, утрата ключа или единственной новой пары после
принятия refresh сервером могут требовать одного явного входа. Восстановление
неопределённого результата ограничено, бесконечного reuse нет. Полный downgrade
V2-записи старым binary не поддерживается. Синтетические 30/180 дней не являются
шестью месяцами реального использования; live ALSE остаётся отдельной проверкой.

- Принятая ревизия и независимое review/security: pending.
- Автотесты и итоговый отчёт по точному дифу: pending.
- Сборка/QA пакета и публичный asset SHA-256: pending.
- Публикация и проверка опубликованного asset: pending.
