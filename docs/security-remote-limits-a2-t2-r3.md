## 2. Инвариант `never`: ни записи в файлы входа, ни POST `/oauth/token` — **цел**

- Выходы `never` стоят до `_prepare_rotation`: Claude `limits.py:338` → `:349`; Codex `:752` → `:767`. Новые проверки, работающие при любой политике (`:322`, `:745`), только возвращают `loggedOut` — ничего не пишут и не запрашивают.
- `_token_response_usable`, `_claude_apply_pair`, `_save_*_guarded` достижимы только после `_prepare_rotation` или в replay под `guarded` (`:301`, `:729`); `flush_pending` — только записи с `policy == "guarded"` (`:411`). Единственная новая запись в ФС — `os.unlink` доказанно мёртвого маркера в `STATE_DIR` из `set_credential_write` (`common.py:390`), файлов входа не касается.
- Проба (а), 8 вариантов файла Claude в `never` на HEAD: `file_same=True` во всех, запросы — только `GET usage` либо ничего. A2-19 (д): `never`, пустой id → 0 запросов. A2-01…A2-03, A2-09, A2-10 — зелёные в полном наборе.

## 3. Ответы на вопросы Юрки

**(а) Claude: проверка полноты `:322` при любой политике.** Регресс показа есть, но узкий и безопасный: **приемлемо, info.** Проба (а) HEAD ↔ `be198ba` (`never`, свежий `accessToken`): `refreshToken: "   "` → HEAD `loggedOut`, 0 запросов, `_signed_out_no_values = True` (панель прячет значения); `be198ba` — `GET usage`, `api_fresh`. `refreshToken: ""`/отсутствует — без изменений (условие `oauth.get("refreshToken")` ложно, usage читается). `accessToken: "   "` при живом refresh → HEAD `loggedOut` (до: GET с пустым Bearer → у живого сервера 401 → `expired`) — скорее улучшение. Триггер — только рукой испорченный файл: Claude Code пишет `refreshToken` строкой из ответа сервера, пробельным он быть не может; A5 (VPS, `never` + `publisher`, настоящий файл CLI) не затрагивается. Инвариант не нарушен (fail-closed). Асимметрия с Codex (`:759` — только перед ротацией) — чистоты ради можно перенести условие под `guarded` перед `:349` (2 строки) в B1; не блокер. **(б) Тексты отказа.** Все `CredentialPolicyRefused` — по-английски, CLI добавляет русский/английский префикс по `common.tr` (`cli.py:212–214`) — единообразно с остальными, приемлемо (косметика nr2-8).
