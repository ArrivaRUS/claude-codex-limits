Сценарий: успешный опрос Codex A → вход B → ошибка live-запроса → более новый rollout B выигрывает у кэша A. `ReaderLocalSnapshot` получает значения B с сохранённым ID A; `readerDidSync` разрешает и журналирует их под меткой A. **Исправление:** переносить идентичность вместе с выбранным показанием; сохранять старый ID только при сохранении именно старого снимка, иначе оставлять показание неатрибутированным.

- **minor · [Sources/RemoteLimits.swift:786](Sources/RemoteLimits.swift:786)** · Импорт проверяет верхнюю границу `asOf`, но не retention. Свежий файл издателя может содержать последнее успешное показание старше 35 дней: `load()` удалит его, следующий синк снова запишет. **Последствие:** просроченная история возвращается после очистки. **Исправление:** перед импортом проверять `asOf >= now − HISTORY_KEEP_DAYS`, используя переданный `now`.

- **minor · [Sources/LimitsMonitor.swift:3276](Sources/LimitsMonitor.swift:3276)** · Дозапись не атомарна относительно ошибки: `O_APPEND` защищает позицию записи, но частичная запись с последующим ENOSPC оставляет оборванный JSON. `catch` возвращает `false` без восстановления; следующая запись приклеивается к повреждённой строке. **Последствие:** потеря событий при чтении журнала. **Исправление:** под сериализацией сохранять исходную длину и откатывать неуспешную дозапись; перед следующей записью восстанавливать незавершённый хвост после аварийного завершения.
