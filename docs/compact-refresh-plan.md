# COMPACT-REFRESH — исправление дизайна 3.2.6

2026-10-08. Основание: пользователь отверг внешнюю оранжевую плашку и нижний текстовый блок. База 3bfdf82. Цель macOS3.2.7; Linux0.4.4 не меняется.

## Требования

Вернуть единую композицию прежней панели: один фон с радиусами, существующая шапка, карточки и нижняя строка приложения. Ручное обновление — компактная иконка рядом с настройками с понятной подсказкой и accessibility name. Ход запроса, результат и адресное действие внутри карточки своего сервиса. Не дублировать имена сервисов и многострочные timestamps под панелью. Сохранить различие времени снимка и следующей попытки; подробности могут быть в tooltip. Сохранить все рабочие контракты3.2.6: single-flight, независимое завершение,30s,Retry-After,quiet refresh/явное восстановление.

## План до реализации

1. UXAnalyst: точная компоновка и визуальные критерии в compact-refresh-ux.md, референс существующего интерфейса.
2. DesignEngineer: только UI-часть LimitsMonitor.swift, соответствующие synthetic UI assertions и версия3.2.7. PureQuotaRefresh/transport/auth/scheduler не менять.
3. CodeReviewer: frozen diff, базовый security-check, exact selftest isolation. При изменении security surface — SecurityAnalyst; иначе отдельный проход не требуется.
4. QA: один exact packaged --subscriptions-selftest после isolation PASS, новый визуальный набор RU/EN Simple/Advanced/one/two/off. DesignReviewer отдельно сравнивает реальные PNG с UX и прежней композицией. Сравнение относится к конкретной ревизии.
5. Координатор: интеграция, публикация/установка по действующим разрешениям, публичный SHA и установленный процесс, документация и урок.
