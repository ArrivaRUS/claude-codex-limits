# macOS 3.4.1: доступ к Связке ключей

Область: macOS writer, уборка поколений, разрешение фонового чтения,
ручной повтор и миграция активной записи 3.4.0. Linux не меняется.
Git, `dist/`, `HEARTBEAT.md`, `decisions/` и `.patches/` не изменяются.

Порядок работы:

1. DeveloperComplex: запись через `security -i` и stdin с пределом 2048 байт;
   сохранение helper permit и журнала; тихая проверка результата.
2. DeveloperComplex: уборка только по атрибутам и тихое нативное удаление,
   отдельный срок повторов; фоновые таймауты требуют ручного разрешения.
3. DeveloperComplex: скрытие панели при интерактивном чтении; переход активного
   поколения с маркером security writer в манифесте; версия 3.4.1.
4. Tester: изолированные selftests до AppKit, проверка старых ожиданий,
   интеграционная проба только на временной связке с синтетическими данными.
5. CodeReviewer: независимое ревью итоговых исходников и тестов.

Проверка здесь: статические проверки исходников и shell-синтаксиса. Swift,
Security.framework и AppKit на Linux недоступны. Сборка, selftests и проверка
`apple-tool:` требуют macOS; недоступная временная связка даёт SKIP с причиной.
Без фактического прогона macOS не считать эти проверки пройденными.

Критерии: секрет только в stdin, без `-U`; уборка не читает данные и не включает
общую паузу; после фонового таймаута нет фоновых чтений до ручного повтора;
миграция использует transition и выполняется один раз; панель восстанавливается;
тестовые данные не обращаются к настоящим учётным данным, gist или API.

Реализованы пункты 1–4 и версия 3.4.1. Независимое статическое ревью охватило
писатель, journal/permit, завершение дочернего процесса, уборку, миграцию,
сохранение запрета фонового чтения и UI. Исправлены найденные старые ожидания
таймаутов, распознавание `permission_required` и классификация тихого вызова
внутри ручного прохода по фактически использованному адаптеру.

Валидация в Linux: `git diff --check`, `bash -n build.sh` и структурные проверки
argv/stdin, ограничения строки, тихой уборки, маркеров и размещения selftests
до AppKit — PASS. Linux-порт и запрещённые области не изменены.
Swift-компиляция, выполнение selftests, временная связка и AppKit — SKIP:
на этой машине Linux, нет Swift и `/usr/bin/security`.
Нативная проба добавлена в selftest: общий production runner, отдельная временная
связка, проверка `apple-tool:`, точного синтетического конверта и неизменности
дубликата; вывод данных связки не печатается.

Остаётся подтвердить на macOS фактический код ошибки `security -i`, ACL и UI.
Тихая проверка атрибутов страхует код возврата; полная строка stdin ограничена
2048 байтами, поэтому чрезмерно длинные credentials отклоняются до запуска.
