# KEYCHAIN-RETRY — отдельное исправление

2026-10-05. База d65df2dda14e09312e87b4d61b00417acda5a00f.

Пользователь сообщил о постоянных запросах доступа к GitHub Credential V2 и поручил продолжить. SecurityAnalyst установил отсутствие общего backoff для V2 чтений; причина первого prompt не установлена.

Принят ограниченный контракт: единый процессный gate для всех V2 store путей; 600 секунд по монотонным часам от ошибки, пропуск не продлевает срок, после срока одна сериализованная попытка. Явный ручной повтор не является login и не обходит сетевые/recovery ограничения. Credentials, ACL, epoch и протокол публикации не меняются. Состояние недоступности не равно missing/revoked. Logout сохраняет tombstone, cleanup откладывается. Гарантия не охватывает успешный Allow, другую запись с тем же именем или restart.

DeveloperComplex реализует отдельно в временной копии; независимый SecurityAnalyst и CodeReviewer проверяют production и изоляцию до интеграции. Фикстуры должны охватыть blocked reads/stage/delete, completion timeout, cleanup, recover, manual double-click, clock changes, pending state preservation. Реальные Keychain, API, пользовательские журналы и обычный запуск приложения запрещены в тестах.

FRESH-4H выполняется параллельно в другой копии; изменения источников интегрируются последовательно после проверки патчей. Никакая публикация пока не выполнена.
