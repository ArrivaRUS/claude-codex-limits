# REMOTE-LIMITS: карточки аккаунтов на macOS

Статус: UX-спецификация на приёмку макетов (G2b/G3), одно направление; макет — `design/remote-limits-card.html`. Ревизия 2026-10-12, база macOS 3.2.7 (`Sources/LimitsMonitor.swift`), PRD `docs/prd-remote-limits.md` (принят G1). Платформа: macOS, окно 360 pt, Simple и Advanced. Linux-трей — вторая очередь, здесь не проектируется.

Обозначения: **аккаунт со входом** — у продукта есть локальный вход на этом компьютере и включён его опрос (N2); **аккаунт без входа на этой машине** — карточка целиком из gist. `<m>` — имя машины-источника показания (V3). `HH:MM` — существующий `quotaTimestamp` (HH:mm сегодня, `dd.MM HH:mm` в другой день). Цвета и шрифты — существующие: `textHi` белый 0,95; `textMid` белый 0,5; `textLo` белый 0,34; `ADV_LINK` `#6B9EF5`; amber `#FF9E2E` (1, 0,62, 0,18); заливка карточки белый 0,04, рамка белый 0,06, радиус 14.

## 1. Главный принцип: ноль новых строк в карточке

Источник и свежесть живут в **существующей** строке 1 футера карточки (`drawQuotaCardFooter`, F = 32 pt, две строки), подпись аккаунта — в **существующей** строке заголовка. Карточка аккаунта без входа геометрически совпадает с карточкой 3.2.7: **+0 pt** к высоте карточки. Окно растёт только от числа карточек (раздел 6). Статус ≤ 2 строк в футере, всё остальное — в подсказке футера (`quotafeedback:<id>`) и её AX value. Тело карточки (кольца, проценты, строки сброса, темп) не уменьшается.

## 2. Заголовок карточки: подпись аккаунта (A3)

Подпись аккаунта `L` = пользовательская подпись (≤ 32 символа), иначе по умолчанию `<Продукт> <план> · <машины>`, например `Claude Max 20x · vps`. `<машины>` — имена машин, публикующих этот аккаунт: этот компьютер первым, остальные по алфавиту, не больше двух имён, далее `+N` (`Codex Pro · mac, vps +1`). План — из снимка аккаунта (`plan`/`tier`), не из локального `claudeTier` (U3).

| Случай | Simple (заголовок 12.5 pt semibold, x+39 … x+w−28) | Advanced (13 pt semibold + плашки) |
|---|---|---|
| Синк выключен или аккаунт есть только на этой машине и он единственный у продукта | как сейчас: `Claude Code` / `Codex` | как сейчас: имя + плашка плана |
| Подпись по умолчанию, остальные случаи | `<Краткий продукт> · <машины>`: `Claude · vps`, `Codex · mac, vps` | `Claude Code` + плашка плана `Max 20x` (9.5 pt, белый 0,09) + после плашки `· vps` 11 pt `textMid` |
| Пользовательская подпись | `L` целиком | `L` вместо имени продукта + плашка плана, без `· машины` |

Не влезает: обрезать **машины** многоточием в конце (`Codex · mac, v…`), имя продукта и пользовательскую подпись не обрезать до 8 знаков; полная `L` — в подсказке заголовка и в AX label карточки.

**Уточнение 2026-10-29 (решение владельца по долгу D2 живого прогона, `Codex · macb…`):** в Simple машины уходят **второй строкой заголовка**, под именем продукта: строка 1 — `<Краткий продукт>` 12.5 pt semibold (`Claude`, `Codex`, или `L`), строка 2 — `<машины>` компактным шрифтом: системный в узком начертании (`NSFont.systemFont(ofSize: 10.5, weight: .regular, width: .condensed)`, цвет `textMid`), по тем же правилам состава (этот компьютер первым, ≤ 2 имён, далее `+N`). Вторая строка есть у **всех** карточек в Simple, когда она есть хоть у одной (п. 11.2: высоты равны); у локального единственного аккаунта без синка строка 2 пустая, но место занято. Обрезание машин многоточием — только если и в condensed не влезает. Advanced без изменений (машины после плашки). Геометрия: заголовок выше на 13 pt, кольцо и футер сдвигаются вниз, окно панели — по правилу раздела 8. Иконка продукта 18 pt (Simple) / 16 pt (Advanced) остаётся — она и отличает продукт при пользовательской подписи.

**Два аккаунта одного продукта** (Codex на маке и Codex B на VPS): две карточки, `Codex · mac` и `Codex · vps`; у каждой свой футер, своё время и своя строка в «Истории и деньгах». **Один аккаунт на двух машинах**: одна карточка `Codex · mac, vps`; строка 1 футера называет машину, чьё показание новее (V3).

## 5. Тело карточки: сброс, темп, затемнение (V6)

- Порог устаревания окна для показания с другой машины — горизонт свежести V4, а не `SNAPSHOT_MAX_AGE` (4 ч) в `metricIsStale`. Дальше работают существующие признаки: серое кольцо и цифры (белый 0,3), «тусклые» числа в строке меню, строки Advanced вида `.stale`.
- Сброс прошёл после `asOf` → окно `окно сброшено` / `window reset` (существующий `limitResetText`), серое кольцо этого окна, старый процент не цветной.
- Simple, без входа на этой машине: **строки сброса остаются** (Сессия / Неделя / модель) во всех состояниях. Сообщение `данные от … · обновите данные` (`limitSimpleStaleCopy`) и проблемное тело с треугольником **не рисуются**: статус уже в футере, а «обновите данные» вводит в заблуждение. Нет ни одного показания → кольца пустые, `—`, строка 1 `Нет данных с vps`.
- Advanced: темп, прогноз («Хватит до сброса» / «Кончится в HH:MM»), план и скорость — от `asOf`. Отдельная строка «Темп по снимку от …» **не возвращается** (снята в 3.2.7); пометка времени — строка 1 футера + строка «Темп …» подсказки. Неверный `asOf` → существующая строка `Нет свежих данных · темп не считаем` (ADV_NOTICE 19 pt, только в этом случае).
- Бейдж-предупреждение заголовка Advanced для аккаунта без входа берётся из столбца «Бейдж Advanced» раздела 4, а не из `limitAuthBadge` («вход истёк» о чужой машине здесь ложен).

## 6. Раскладка, порядок и высоты (V1, V2)

**Порядок (V2):** Claude-аккаунты, затем Codex; внутри продукта первым аккаунт со входом, далее по `L` (без учёта регистра, по правилам локали), при равенстве — по метке. Скрытые (N1) не показываются; группа «аккаунт не указан» карточки не имеет.

**Simple — сетка 2 колонки.** Ширины и отступы 3.2.7: x = 16 и 186, w = 158, gap = 12; одна карточка — x = 16, w = 328. `n` видимых карточек → строк `ceil(n/2)`; при нечётном `n ≥ 3` последняя карточка широкая (x = 16, w = 328, как Simple-одиночка). Высота всех карточек одна: `cardH = 152 + scopedRowExtra + 32`, где `scopedRowExtra` считается по **всем** видимым карточкам. Строка `i` начинается с `58 + i·(cardH + 12)`. Высота окна: `286 + scopedRowExtra + 32 + (rows − 1)·(cardH + 12)`. Шкала интервалов и авторство идут по прежней формуле от низа последней строки. Пример: Claude (vps) | Codex (mac) / Codex (vps) широкая → 333 + 211 = **544 pt**.

**Advanced — стопка как сейчас** (x = 15, w = 330, gap = 5); карточка без входа той же высоты, что локальная того же продукта. Окно выше экрана → существующая прокрутка главной панели (`mainScroll`).

| Что добавляется | pt |
|---|---|
| Строка источника, статус, подпись в заголовке | **0** (существующие строки) |
| Каждая следующая строка Simple (3-я и 4-я карточки) | `cardH + 12` = 199/211 |
| Каждая доп. карточка Advanced | её высота + 5 (≈ 160 Claude, ≈ 125 Codex) |
| Advanced «История и деньги»: переключатель на ≥ 3 аккаунта уходит на свою строку | +22 |
| Advanced деньги: строка на каждый аккаунт сверх двух | +19 |

**История и деньги (Advanced, F7):** переключатель `Claude | Codex` становится переключателем аккаунтов: подпись сегмента — заголовок Simple из раздела 2 (`Claude`, `Codex · mac`, `Codex · vps`), группа «не указан» — `Codex · не указан` / `Codex · unlabelled`. При ≤ 2 сегментах он справа от заголовка, как сейчас; при ≥ 3 — на строке под заголовком, на всю ширину 308 pt, сегменты не обрезаются. Таблица денег — по строке на аккаунт (`Claude Max 20x · vps · $200/мес`); цена без пометки «оценка», если план есть в снимке (U3).

## 7. Строка меню (V8)

- Строка ленты на продукт, как сейчас (максимум две: Claude сверху, Codex снизу). Числа строки — у **выбранного** аккаунта продукта. По умолчанию это аккаунт со входом, без него — первый по V2 (на маке без Claude — Claude с VPS). Выбранный аккаунт скрыт или пропал → снова значение по умолчанию.
- Устаревание отмечается так же, как у локальных: окно, которое `metricIsStale` (с горизонтом V4), рисуется тусклым (альфа 0,4), разделители `/` и `%` тускнеют, если устарели все окна. Состояния 2, 3, 5, 6 → все числа строки тусклые; 4 при свежем показании — обычные; 7 — чисел нет (как при локальном `loggedOut`, №14; уточнение 2026-10-28). `signed_out`/`expired` на источнике **не** прячут числа (в отличие от локального `loggedOut`): показываются последние значения, тусклые.
- Новое: подсказка кнопки строки меню (`statusItem.button.toolTip`) — по строке на продукт: `Claude Max 20x · vps — данные с vps от 15:43` / `Claude Max 20x · vps — data from vps at 15:43`.
- Выбор аккаунта — в Настройках, раздел 9.

## 8. Футер Auto (V9)

Шкала `15м 30м 1ч 4ч | А` и её подсветка описывают **только локально опрашиваемые** аккаунты (N2 включён и есть вход). Аккаунты без входа на этой машине не подсвечивают сегменты и не упоминаются в подсказке `А`. Нет ни одного локально опрашиваемого входа → существующее состояние `noSubscriptions`, но текст подсказки меняется: `Этот компьютер ничего не опрашивает. Аккаунты с других компьютеров обновляются по их расписанию — оно в подсказке карточки.` / `This computer polls nothing. Accounts from other computers update on their own schedule, shown in the card tooltip.` Подсказка `А` с несколькими аккаунтами одного продукта (невозможно по A7) не нужна; имя в подсказке остаётся продуктом: `Авто: Codex → 15 мин`. Расписание источника — только в подсказке карточки (раздел 4).

## 9. Настройки (N1–N4, V10)

Порядок блоков; геометрия строк — существующая (`SET_ROW_H` 36, `SET_GAP` 14, `SET_CAP_H` 16, карточка радиус 12, x = 16, w = 328).

1. **ОБЩИЕ** — без изменений.
2. **ОПРАШИВАТЬ НА ЭТОМ КОМПЬЮТЕРЕ** / **POLL ON THIS COMPUTER** — замена `СОБИРАТЬ И ПОКАЗЫВАТЬ`; та же строка 36 pt с двумя переключателями `Claude Code` / `Codex` (N2). Под карточкой, **только если нет входа в GitHub**, строка-ссылка 10.5 pt `ADV_LINK` высотой 20 pt: `Аккаунты с других компьютеров — после входа в GitHub ›` / `Accounts from other computers appear after GitHub sign-in ›` → прокрутка к блоку GitHub. Это ответ на V10.
3. **АККАУНТЫ** / **ACCOUNTS** — новый блок (N1, N4). Показывается, если есть вход в GitHub или в кэше есть аккаунты без входа на этой машине; иначе скрыт (настройки пользователя без синка не меняются). Строка аккаунта 36 pt: иконка продукта 16 pt (x+15); строка 1 `L` 12.5 pt `textHi` (x+42, обрезка многоточием до 180 pt); строка 2 10 pt `textLo`: `Max 20x · vps · без входа здесь` / `Max 20x · vps · not signed in here` или `Pro · mac, vps · вход здесь` / `signed in here`; справа карандаш 24×24 (hit `edit:<метка>`) и переключатель видимости 34×16. Скрытый аккаунт: `L` в `textMid`. Строки группы «аккаунт не указан» (V7): `Codex · аккаунт не указан` / `Codex · unlabelled account`, строка 2 — машины, только переключатель. Новый аккаунт появляется видимым (N1).
   - Правка подписи: карандаш → поверх строки 1 нативное поле (`NSTextField`, 12.5 pt) со счётчиком `12/32` справа в 10 pt `textLo`; Enter — сохранить, Esc — отменить, пустое поле или ссылка `Сбросить` / `Reset` → подпись по умолчанию. 6. **ДРУГИЕ КОМПЬЮТЕРЫ · ЧЕРЕЗ GITHUB** — **показывать в обоих видах** (сейчас только Advanced, `syncBlockShown`). Содержимое блока без изменений.

## 10. Пустые и переходные состояния

| Ситуация | Что видно |
|---|---|
| Ни одной карточки и нет входа в GitHub (все опросы выключены, кэша нет) | Существующее пустое состояние с «Настройки ›» + строка 10.5 pt `textMid`: `Включите опрос или войдите в GitHub, чтобы видеть аккаунты с других компьютеров` / `Turn on polling or sign in to GitHub to see accounts from other computers` |
| Опрос продукта выключен, аккаунтов этого продукта в gist нет | Карточки нет (как сейчас у выключенного продукта); заглушку «Не настроен» не рисовать |
| Вход в GitHub есть, первое чтение gist ещё идёт | Карточек без входа ещё нет; новых заглушек нет; после чтения карточки появляются без анимации |
| Группа «аккаунт не указан» (V7, Could) | Только в Advanced «История и деньги» (сегмент и строка денег) и в списке «Аккаунты»; карточки лимитов нет |

## 11. Приёмка (проверяемые пункты)

1. Мак без входа Claude, VPS опубликовал Claude Max 20x 10 мин назад: в Simple и Advanced карточка `Claude · vps` (Advanced: `Claude Code` + `Max 20x` + `· vps`) с процентами сессии, недели и модели и строкой 1 `Данные с vps от HH:MM`; в Advanced есть темп, прогноз и деньги $200 без «оценки».
2. Высота карточки без входа равна высоте локальной карточки того же продукта в том же виде (разница 0 pt); футер ≤ 2 строк, не обрезает время.
3. Каждое из состояний 1–7 и фаз ручного обновления воспроизводится фикстурой в RU и EN, в узкой (158) и широкой (328) Simple и в Advanced; тексты точно по таблицам; полный текст в tooltip и AX value; цвета: amber только в 3–5, `ADV_LINK` в 6–7.
4. Ни в одном состоянии карточки без входа нет `claude login`, `claude → /login`, «Как починить?», экрана `claudefix`, бейджа `вход истёк`; клик по карточке открывает страницу использования.
5. Auto на VPS 4 ч, показание 3 ч 50 мин, файл VPS свежий → состояние 1 (не серое). VPS выключен 40 мин → состояние 5 `vps не на связи с HH:MM`, значения видны.
6. `asOf` 10:00, сброс сессии 11:00, сейчас 11:20 → `окно сброшено`, кольцо сессии серое. `asOf` в будущем > 5 мин → `Нет свежих данных · темп не считаем`.
7. Два Codex-аккаунта → две карточки `Codex · mac` и `Codex · vps`, раздельные сегменты истории и строки денег. Один Codex на двух машинах → одна карточка `Codex · mac, vps`.

9. Шкала Auto подсвечивает интервалы только локально опрашиваемых аккаунтов; при нуле локальных — `noSubscriptions` с новым текстом подсказки.
10. Строка меню: по умолчанию Claude с VPS; выбор в Настройках меняет числа; состояния 2/3/5/6/7 → тусклые числа; tooltip кнопки называет подпись и источник.
