## Текущее поведение

Подписки Claude Code/Codex включаются независимо. Фиксированные интервалы — **15/30/60 минут**, по умолчанию **30**. Auto по каждой подписке меняет интервалы **15 → 30 → 60 → 240 минут**. Подробности и ограничения ручного опроса — в [README Linux](../../linux/README.md).

GH-AUTH-STABLE сохраняет целую защищённую выдачу access/optional refresh и автоматически продлевает её, когда issuer выдал необходимые поля. Старый здоровый вход не требует перевхода ради миграции; новый явный login запрашивает `gist offline_access`. Автовосстановление не гарантируется при внешнем отзыве, истёкшем refresh или невосстановимой потере выдачи. Выход остаётся локальным. [Гайд](../../docs/project-guide.md), [архитектура](../../docs/architecture-github-auth.md).

FRESH-4H сохраняет снимок при сбое и не помечает его устаревшим только по возрасту до **14400 секунд включительно**; подтверждённый auth и завершившиеся окна рассматриваются отдельно. KEYCHAIN-QUIET в **macOS 3.2.5** запрещает фоновые диалоги GitHub Keychain; интерактивная попытка разрешена по явному действию пользователя. Это macOS-изменение, Linux остаётся 0.4.4. [Гайд](../../docs/project-guide.md).

MANUAL-REFRESH — [предложение](../../docs/manual-refresh-proposal.md), а не реализация обхода текущего расписания. Производящий код для этого сценария не поручен.
