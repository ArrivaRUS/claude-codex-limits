## Текущее поведение 0.4.5

В локальном UI-патче нижние «Проверено»/«Данные» и видимое время убраны в обоих видах и языках. Время данных и детали остаются в подсказке; сообщения ошибки, обновления, ожидания и действия сохраняются. Патч установлен локально; интерактивный smoke и реальные API не подтверждены.

Подписки включаются независимо. Фиксированные интервалы — **15/30/60/240 минут**, по умолчанию **30**; Auto сохраняет собственный интервал каждого включённого сервиса и показывает их подсветкой рядом с «А». Компактная иконка обновления находится рядом с Настройками, результаты — внутри карточек.

MANUAL-REFRESH реализован: явное нажатие обходит локальное расписание и сетевой backoff, сохраняя режим. Каждый сервис имеет отдельный запрос и результат; ответ одного не ждёт другого, ошибочный сервис можно повторить отдельно. Защита от повторов — 30 секунд от начала попытки, реальный серверный Retry-After соблюдается. Неизменившиеся проценты после успешного ответа допустимы; fallback сохраняет старое время данных. [Шаги и предпосылки](../../docs/project-guide.md), [Linux-контракт](../../docs/linux-manual-refresh-contract.md).

GH-AUTH-STABLE сохраняет защищённую выдачу access/optional refresh и продлевает её, когда issuer выдал необходимые поля. Выход остаётся локальным; внешний отзыв или потеря выдачи могут требовать нового входа. [Архитектура](../../docs/architecture-github-auth.md).

FRESH-4H сохраняет снимок при сбое и не считает его устаревшим только по возрасту до **14400 секунд включительно**; подтверждённый auth и завершившиеся окна рассматриваются отдельно. macOS KEYCHAIN-QUIET запрещает фоновые диалоги GitHub Keychain; Linux использует свои CLI-файлы и native Secret Service. macOS Keychain permit на Linux не переносился.
