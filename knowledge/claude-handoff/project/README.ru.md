# Claude Codex Limits

[English](README.md) · **Русский**

<p align="center">
  <img src="docs/banner.png?v=314" alt="Claude Codex Limits — лимиты в строке меню macOS" width="820">

Маленькое приложение для строки меню macOS, которое показывает, сколько у вас осталось
лимитов **Claude Code** и **Codex** — одним взглядом, прямо в верхнем трее.

В каждой строке — `сессия% / неделя%` (скользящее 5‑часовое окно и 7‑дневное окно),
слева иконка продукта; какие именно два числа показывать — решаете вы.
По клику на иконку в трее открывается подробная панель.

## Возможности

- **Два продукта — один взгляд.** Claude Code (рыжий) над Codex, проценты `сессия / неделя`.
- **Живые данные.** Оба тянутся с тех же бэкендов, что и их CLI, поэтому Codex совпадает со своей веб-страницей (а не устаревший локальный кэш).
- **Честно при протухшем входе.** Если сохранённый вход Claude Code истёк окончательно, карточка так и говорит («Вход устарел · Как починить?»), а тап по ней ведёт в короткую инструкцию `claude` → `/login`; при этом приложение перестаёт стучаться в API заведомо мёртвым токеном. Один новый вход — и всё оживает само.
- **Лимиты по моделям.** У модели со своим 7‑дневным лимитом (например, Fable) появляется собственная пилюля с процентом и строка со временем сброса. Обычно именно в него упираешься первым: он может быть на 100%, когда общий недельный ещё не исчерпан. Название модели берётся с бэкенда, так что новые появятся сами.
- **Расширенный режим.** Второй вид панели для тех, кто хочет лимитами *управлять*, а не только поглядывать. У каждого окна — строка темпа: где по линейному плану вы должны быть сейчас, на сколько пунктов опережаете, средняя скорость расхода и вердикт словами — «Хватит до сброса (прогноз 53%)» или «Кончится в 09:37, за 2 ч 13 мин до сброса». Ниже — расход за 7 дней столбиками стопкой по моделям, календарь за 35 дней и деньги: сколько стоит день по подписке и сколько те же токены стоили бы по ценам API. Отдельно по Claude Code и Codex. Настройки → «Вид панели».
- **Несколько компьютеров — одна учётка.** Войдите в GitHub в настройках, и каждый компьютер с утилитой будет складывать свой локальный расход в один секретный gist, а каждая копия — показывать общие столбики, календарь и деньги. Передаётся только сводка токенов по дням и моделям — без промптов, путей и названий проектов. Есть версия для Astra Linux — см. [Linux](#linux-astra-linux) ([протокол](docs/sync-protocol.md)).
- **Строка меню — на ваш выбор.** Выбираете, какое число стоит слева от слэша, а какое справа (5‑часовой, недельный или лимит модели), и в каком порядке; правое можно погасить и оставить одно число. Настройки → «В строке меню». Трей меняется сразу по нажатию.
- **Сбросы Codex.** Если накоплены сбросы лимита («банкинг сбросов»), на карточке Codex показывается маленький бейдж ⟳ с их количеством.
- **Цветовые предупреждения.** Цифры и кольца желтеют при ≥50% и краснеют при ≥80% лимита.
- **Подробная панель.** Клик по иконке — кольцевые гейджи, точные проценты, время сброса.
- **Клик по карточке** открывает страницу с лимитами в браузере.
- **Один или оба продукта** — если настроен только Claude Code или только Codex, трей и панель сворачиваются в одну строку / одну карточку.
- **Открытие панели тут же форсит свежее обновление.**
- **Интервал обновления** — 5 или 15 минут на выбор (5 — минимум: при более частом опросе с нескольких компьютеров одной учётки сервер начинает отказывать).
- **Звуковые уведомления (опционально)** — весёлый перезвон при *сбросе* 5ч/недельного лимита и грустный тон при достижении **любого** лимита, включая модельный; звук выбирается отдельно для каждого события в настройках (⚙).
- **Автоматические обновления** — проверка новых релизов в фоне (при запуске + каждые 6 ч); когда появляется новее, в трее и на шестерёнке ⚙ загорается точка. В настройках **Что нового** показывает релиз-ноуты за все пропущенные версии, а **Скачать** → живой прогресс-бар → **Установить и перезапустить** сразу ставит последнюю. Без Sparkle и нотаризации.
- **Два языка (RU / EN)** — переключение всего интерфейса между русским и английским в настройках; релиз-ноуты тоже на выбранном языке. По умолчанию русский.
- **Светлая и тёмная** строка меню, чётко на retina.
- **Автозапуск при входе** — тумблер прямо в настройках; без иконки в Dock, без сторонних зависимостей.

## Как это работает

**Claude Code** (лимиты подписки). Приложение читает ваши существующие OAuth‑креденшелы
Claude Code из связки ключей macOS (`Claude Code-credentials`), обновляя access‑токен
ровно так же, как это делает CLI Claude Code, и запрашивает эндпоинт использования
Anthropic `GET /api/oauth/usage`. **Это не тратит вашу квоту** — берутся только
`five_hour.utilization` (сессия), `seven_day.utilization` (неделя) и структурированный
массив `limits[]` для недельных лимитов по моделям (`kind: "weekly_scoped"`, название из
`scope.model.display_name`). Старые поля по моделям (`seven_day_opus` и подобные) теперь
возвращают `null`, так что `limits[]` — единственный источник для них.

**Codex** (OpenAI). Приложение тянет **живые** данные с того же бэкенда, что и Codex CLI —
`GET /backend-api/wham/usage` — при каждом обновлении (запуск, таймер 5/15 мин и открытие
панели), авторизуясь локальным токеном из `~/.codex/auth.json` (с авто‑обновлением через
токен‑эндпоинт OpenAI, когда он протух). `primary_window` — 5‑часовое окно, `secondary_window`
— 7‑дневное. Если живой запрос не прошёл, берётся самый свежий локальный журнал сессий
(`~/.codex/sessions/**/rollout-*.jsonl`).

**Расширенный режим.** Для темпа хватает текущего показания и времени сброса окна. Столбики,
календарь и деньги берутся из локальных журналов самих CLI — `~/.claude/projects/*/*.jsonl` и
`~/.codex/sessions/**/rollout-*.jsonl`, — где записаны токены и модель каждого хода. Поэтому проценты
и темп — это вся учётка, с какого бы компьютера вы ни работали, а столбики, календарь и деньги — то,
что запускалось на этом Mac, плюс на других компьютерах, вошедших в тот же GitHub, если включить синхронизацию. Приложение индексирует журналы инкрементально (читает только байты, дописанные с прошлого раза) и оценивает
токены по встроенной таблице публичных цен API по моделям; неизвестные модели не оцениваются
вовсе, а не угадываются. Цена подписки, где можно, выводится из плана (у Claude — из tier
лимитов) и редактируется в настройках; названия планов Codex на публичные цены не ложатся,
поэтому там оценка, пока вы не зададите свою. Ещё приложение хранит собственные замеры
использования (35 дней, в `~/.claude-limits-monitor/`), чтобы темп со временем опирался на
ваш недавний расход, а не только на среднее по окну.

Никуда ничего не отправляется, кроме авторизованных запросов использования в Anthropic и OpenAI
(от вашего имени). Никакой телеметрии и сторонних сервисов. Рантайм‑кэш и резервная копия
креденшелов хранятся в `~/.claude-limits-monitor/`.

## Установка

### 1. Установка одной командой (рекомендуется)

```bash
curl -fsSL https://raw.githubusercontent.com/ArrivaRUS/claude-codex-limits/main/get.sh | bash
```

Скачивает последний релиз и ставит его прямо в **Applications** **без диалогов
Gatekeeper** — приложение, скачанное через `curl`, не получает карантин-атрибут,
поэтому macOS не помечает его как «повреждённое» или «от неизвестного разработчика».
Автозапуск при входе остаётся **выключен**, пока вы не включите его в настройках.

### 2. Из .dmg

1. Скачайте `ClaudeCodexLimits-3.1.4.dmg` со страницы [Releases](../../releases).
2. Откройте и перетащите **Claude Codex Limits** в **Applications**.
3. Запустите. Сборка не нотаризована, поэтому на **macOS Sequoia / Tahoe** первый
   запуск блокируется. Сделайте один раз:
   - В окне блокировки нажмите **«Отмена»** (⚠️ **не** «Переместить в Корзину»).
   - Откройте **Системные настройки → Конфиденциальность и безопасность**,
     прокрутите вниз, нажмите **«Всё равно открыть»** и подтвердите.
   - **Если кнопки «Всё равно открыть» нет**, снимите карантин-атрибут в Терминале
     и затем откройте приложение обычным способом:
     ```bash
     xattr -dr com.apple.quarantine "/Applications/Claude Codex Limits.app"
     ```
4. Иконка появится справа в строке меню.

### Из исходников

```bash
git clone https://github.com/ArrivaRUS/claude-codex-limits.git
cd claude-codex-limits
./install.sh        # собрать, поставить в /Applications, включить автозапуск, запустить
```

Требуется: macOS 13+, командные инструменты Xcode (`swiftc`). Ставить пакеты не нужно.

### Linux (Astra Linux)

Порт для Linux проверен на Astra Linux SE 1.8 (KDE / Fly). Он даёт значок в трее с теми же
процентами, панель с простым и расширенным видом и синхронизацию расхода с Mac через тот же gist.

1. Скачайте `claude-codex-limits_0.3.0_all.deb` из релиза [Linux 0.3.0](../../releases/tag/linux-v0.3.0).
2. Откройте файл двойным щелчком и нажмите «Установить» или поставьте из терминала:
   ```bash
   sudo apt install ./claude-codex-limits_0.3.0_all.deb
   ```
   Зависимости (`python3-pyqt5`, `python3-dbus`) apt возьмёт из репозитория ОС.
3. Запустите **Claude Codex Limits** из меню приложений. Дальше значок будет запускаться сам.

Без прав администратора можно поставить в домашний каталог: `git clone` и `sh linux/install.sh`.
Подробности — в [linux/README.md](linux/README.md).

## Использование

- **Левый клик** по иконке в трее → открыть/закрыть панель.
- **Клик по карточке** → открыть страницу лимитов продукта в браузере.
- **Кнопка обновления** (вверху справа панели) → обновить сейчас.
- **Пилюли интервала** (внизу) → 5 / 15 минут.
- **Кнопка выключения** (внизу справа) → выход.
- **Правый клик** по иконке → запасное меню (Обновить / Автозапуск / Выйти).

## Приватность и безопасность

Приложение читает только **ваши собственные** локальные креденшелы и журналы и общается
только с API Anthropic и OpenAI от вашего имени (те же эндпоинты, что и у их собственных CLI).
Оно не содержит и не передаёт секретов. Исходник — один читаемый Swift‑файл, его можно
прочитать. Используйте на своё усмотрение.
