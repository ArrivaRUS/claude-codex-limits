## Что изменилось после архива

- Выбор подписок теперь независим для Claude Code и Codex. Фиксированные интервалы **15/30/60 минут**, default **30**; Auto переключает по продуктам **15 → 30 → 60 → 240 минут**, текущая частота видна рядом с «А». Старые 1/5 минут мигрируют на 30. Открытие панели в Auto не ускоряет опрос, а текущий ручной запрос подчинён его ограничениям. [README Linux](../../linux/README.md), [Auto UI](../../design/auto-poll-ui.md).
- AUTH-1 разделяет устаревшие данные и подтверждённые проблемы входа, не предлагает Claude login для Codex и не выдумывает `asOf`. [Контракт](../../docs/auth-hints-fix.md).
- GH-AUTH-STABLE реализует защищённую целую выдачу access/optional refresh, immutable generations, сохранение candidate и восстановление незавершённой операции. Новый явный login запрашивает `gist offline_access`; legacy healthy session сохраняется без обязательного перевхода. Обслуживание входа/обмен независимы от Advanced и Auto опроса лимитов. Внешний revoke, истёкший refresh, утрата ключа или единственной новой пары остаются границами. Выход — локальный, без автоматического server revoke. [Архитектура](../../docs/architecture-github-auth.md), [гайд](../../docs/project-guide.md), [протокол](../../docs/sync-protocol.md).
- FRESH-4H (macOS 3.2.4/Linux 0.4.4) сохраняет снимок при ошибке; до **4 часов включительно** возраст сам по себе не означает stale. Темп оценивается на момент `asOf`, окна независимы; auth и завершение окна — отдельные состояния. Плановая попытка после срока не гарантирует успешный ответ сети. [План](../../docs/freshness-4h-plan.md), [проверки выпуска](../../docs/freshness-keychain-verification.md).
- KEYCHAIN-QUIET (только macOS 3.2.5) запрещает фоновые GitHub Keychain диалоги для V2/legacy, startup/wake, refresh и cleanup. Недоступность не приравнивается к missing/revoked; интерактивная попытка ограничена явным действием и отменой. Точный live-механизм повторов у пользователя не установлен. [Контракт](../../docs/keychain-no-background-prompts.md), [проверки](../../docs/keychain-quiet-verification.md).
- MANUAL-REFRESH предлагает явное «Обновить сейчас» с видимым результатом и раздельными результатами сервисов. **Это proposal: реализация не поручена.** Не описывать предложенный обход локальных пауз или защиту 30 с как существующее поведение. [Предложение](../../docs/manual-refresh-proposal.md).

## Проверки и незакрытые долги

Независимое ревью исправленного bwrap runner — PASS. На системных библиотеках Astra 1.8.5 / Python 3.11.2 / PyQt5 5.15.9 приняты **306 тестов PASS, 0 fail/error/skip/xfail, exit 0**, 71.276 с; 192 свежих PNG, четыре просмотрены QA без clipping. Existing layout tests покрывают Breeze/Fusion × RU/EN × три состояния. Первый прогон с ошибками временного runner не засчитан. Тесты изолированы от host credentials/DBus/display и внешней сети (только loopback); подробности и runner hashes — в [Linux-отчёте](../../docs/alse-0.4.4-verification.md). Исторические CI, Swift selftests, bitmap QA и пакетные PASS следует читать с exact revision и ограничениями в исходных отчётах. Они не доказывают текущую live ALSE, native Keychain/KWallet, реальные OAuth и клики.

В [бэклоге](../../backlog.md) отдельно остаются:

1. **Live ALSE** — установка 0.4.4 и старт GUI-процесса подтверждены; пользователь подтвердил значок и открытие панели в KDE/X11. Остаются остальные hover/click, шрифты, native KWallet, OAuth/API и sleep/wake.
2. **Аудит Auto** — независимое заключение по ранее опубликованному алгоритму на `e6e2f2e`: поведение, ошибки, сохранение состояния, границы запросов.
3. **Sync debt** — L-4/SS-sweep, F-3, межпроцессная отмена и Ctrl+C, legacy/DBus/lock/сигнальные сценарии, устойчивость state/fsync. Перед исправлением сверить актуальность каждого пункта.

Тестовая изоляция обязательна: без настоящих credentials, keyring, пользовательских журналов и запросов к gist/API. Временные XDG-папки сами по себе недостаточны; применять [урок 006](../../.patches/006-tests-touch-real-keyring.md) и актуальный [гайд проверок](../../docs/project-guide.md).

## Продолжение

Согласованный шаг после «давай за работу» — Linux install + isolated validation и актуализация знаний — завершён. Точные команды, ревизия, результаты и границы находятся в [Linux-отчёте](../../docs/alse-0.4.4-verification.md); остаются независимое документационное ревью и интеграция координатором. Режим — **codex-only**, инструкции — [AGENTS](../../AGENTS.md) и [codex-team](../../docs/codex-team.md). Исторические назначения Claude/mixed, старые планы и разрешения не являются новыми заданиями. Выданные владельцем разрешения учитывает координатор в текущем scope.
